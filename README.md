# Разделение ролей (Express + express-session)

Веб-приложение на Node.js и Express: страница входа с выбором роли, хранение пользователя в сессии и раздача страниц в зависимости от роли (user, moderator, admin).

## Запуск

```bash
npm install
npm start
```

Сервер открывается на http://localhost:3000. Вход возможен с ролями: Пользователь, Модератор, Администратор.

## Структура проекта

- `server.js` — сервер Express: сессии, маршруты `/`, `/user`, `/moderator`, `/admin`, `/logout`
- `public/login.html` — страница входа с выбором роли
- `public/user.html`, `public/moderator.html`, `public/admin.html` — страницы ролей
- `public/style.css` — оформление страниц
- `скриншоты/` — скриншоты работы приложения и кода

## Проверка доступа

После входа под своей ролью прямой переход на чужую страницу (`/admin`, `/moderator`) возвращает статус 403 и сообщение «Доступ запрещён». Без сессии все страницы, кроме входа, перенаправляют на `/`. Кнопка «Выйти» уничтожает сессию и возвращает на страницу входа.
